How to read this

still mark = grade A — an audited / settled reading.
shimmering mark = grade C — uncertain; the amplitude is the uncertainty. (Grade B sits between: a faint life.)
cyan = an independent number — an audit, a census, a court finding: held by a third party, not the party being judged.
amber = a seller-owned number — the party being judged counting its own audience, setting its own price, billing its own log.
struck red = a corrected / DEAD claim — a popular legend this piece knocks down (contested claims show both values instead of a strike).

Reduced motion: every shimmer becomes a static hatched band — denser for a softer grade — so the uncertainty is still seen, just not moving.
