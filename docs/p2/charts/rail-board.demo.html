The modules did not load.

Chrome refuses <script type="module"> imports over file://, and every browser refuses to fetch JSON from one. Serve the repository root over http:

cd /path/to/chipandadmarketresearch && python3 -m http.server 8000
then open http://localhost:8000/docs/p2/charts/rail-board.demo.html
