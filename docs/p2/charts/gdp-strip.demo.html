The share-of-GDP strip.

The chart most likely to mislead, so it is built to be argued with. Start on the window the familiar version of this story is read from and 2000 is the highest reading on screen. Widen the window and 1922 walks in above it. No number changes; only how far back the window reaches. Every reading is a dated claim with its own interval, its own source grade and its own basis in the record's own words. Nothing is joined into a line, because the record holds no annual series.
