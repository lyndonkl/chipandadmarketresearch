Self-check

The module audits its own claims before it draws anything.

Two sources of truth is a bug waiting for 2am. verifyTokenParity() reads the computed custom properties back out of tokens.css and throws if they have drifted from the JavaScript. auditPalette() recomputes every contrast figure. auditReducedCoverage() throws if any verb has been added without a stated alternative encoding. The last two cards are specimens, not audits: they prove the cases they name and nothing wider. Mode symmetry as a whole is enforced by review — motion.js deliberately ships no audit for it, because the one it used to ship compared declared argument counts, which every verb here makes identical by construction.

Palette

Eight colours. Each one means exactly one thing.

The contrast figure is measured against Bone at load. OBJ is WCAG 1.4.11 for a non-text graphical object and wants 3:1. TEXT is WCAG 1.4.3 at body size and wants 4.5:1. Where the drawing value fails as text, a darkened sibling is exported beside it, and the raw value throws if it reaches a glyph.

Colour vision

Money against the count. Every simulation below is at full severity, under two independent models — Machado, Oliveira & Fernandes 2009, and Viénot, Brettel & Mollon 1999 — because on this palette the two disagree, and the guard takes the worse of them.
