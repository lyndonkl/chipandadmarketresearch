P2 · team B3 · the pull ring, its own test page

The control five architects expected readers to miss.

A small ring sits inside every machine part. Pull one and that part is lifted out of all seven machines at once. It is the only way to compare one era with another without scrolling twice, and a comparison tool nobody finds is not a tool. The piece therefore teaches it once, in era 1, in a moment the reader cannot skip.

This page runs that teaching sequence on its own, so it can be watched a step at a time. Turn the handle to fire it. Reset the lesson to run it again. Switch the motion toggle to reduced and run it once more: the ring does not tug, it rests three pixels proud, and the sentence arrives at once. That is a different encoding of the same fact, not a shorter one.
