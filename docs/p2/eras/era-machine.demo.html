P2 · The Attention Economy · team B3 · the seven era machines

Seven machines that set a price.

Each era is one machine. Eight parts, in the same eight places every time, so the part that counts the audience in 1880 sits where the part that counts it in 2019 sits. One part can be turned. Turn it, and the machine shows you what that rule priced.

Every number on this page is a claim from the frozen record. Where a claim's interval is wider than the cut, there is no middle value at all — the bar is the whole reading, and the machine has no number to print. Where the record refuses to place a reading in time, the year is drawn as an object with a name on it rather than left blank.
